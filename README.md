# Sistemas Operativos

Presentación interactiva de siete temas. El recorrido principal contiene diez diapositivas sobre **Hilos** y **Planificación de la CPU**.

## Cómo abrirla

Abre `index.html` en un navegador. Usa **Siguiente** para avanzar, **Temario** para ver los siete temas y **Términos** para consultar las definiciones de cada diapositiva.

[Apuntes de Sistemas Operativos de la ULL](https://ull-esit-sistemas-operativos.github.io/ssoo-apuntes/)
