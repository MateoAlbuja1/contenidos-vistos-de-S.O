# Sistemas Operativos

Presentación interactiva de siete temas. El recorrido principal contiene diez diapositivas sobre **Hilos** y **Planificación de la CPU**.

## Cómo abrirla

Abre `index.html` en un navegador. Puedes hacerlo directamente desde la carpeta del proyecto.
Usa **Siguiente** para avanzar, **Temario** para ver los siete temas y **Términos** para consultar las definiciones de cada diapositiva.

## Estructura del proyecto

- `index.html` contiene la estructura de la página y carga los archivos del proyecto.
- `styles/presentation.css` define el diseño y su adaptación a pantallas pequeñas.
- `scripts/app.js` controla la navegación y muestra cada diapositiva.
- `scripts/content/` contiene las diapositivas, el temario y el glosario.
- `scripts/demos/` contiene los controles y el estado de las simulaciones.
- `scripts/core/` contiene el cálculo de planificación y funciones de interfaz reutilizadas en las demostraciones.
